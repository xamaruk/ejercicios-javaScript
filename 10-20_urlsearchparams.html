Recepción de parámetros por URL

Para acceder a los parámetros que lleguen a través de la URL tenemos la clase de JS URLSearchParams.

Esta clase puede trabajar a partir de un dato devuelto por la clase URL, o bien de window.location o bien de un string con toda la información.

En el primer caso, podemos acceder a la ruta completa de este modo: let ruta = window.location.search

Pero es más correcto hacerlo creando una nueva instancia de la clase URL:


            let ruta = new URL(window.location);

En el segundo caso sería algo así:


            let ruta = new URL("https://example.com?data=texto&num=5");

Pero en ambos casos, a partir de ahí acceder a sus parámetros, almacenados en la propiedad search del objeto: 


                let params = new URLSearchParams(ruta.search);

Eso nos va a permitir acceder a las propiedades y métodos de la clase URLSearchParams. Entre ellos tenemos métodos para acceder a un dato concreto, o métodos para iterar todos los datos del objeto y leerlos. La clase también contiene métodos para añadir o eliminar parámetros al objeto.

Leer un parámetro conociendo su nombre de antemano (método get())

Sí se que en la ruta llegan dos parámetros llamados "data" y "num" puedo leerlos así:


                let dato = params.get("data");
                let numero = params.get("num");

Iterar las propiedades de los parámetros

Si no conocemos los nombres de los parámetros podems usar los métodos entries() o forEach() para iterar el objeto y acceder a ellos:

Entries()


        for (const [key, value] of params.entries()) {
            console.log(`entrie ${key} => ${value}`);
        }

forEach()


        params.forEach((value, key) => {
            console.log('forEach', key, '=>', value);
        });
