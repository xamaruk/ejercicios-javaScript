# Ejercicios JavaScript

Este repositorio contiene una colección de ejercicios prácticos de JavaScript desarrollados como páginas HTML. Cada archivo representa un ejercicio o mini proyecto centrado en conceptos como variables, condicionales, arrays, DOM, cadenas, funciones y manipulación del navegador.

## Contenido principal

- `index.html`: página principal de acceso a los ejercicios.
- Archivos HTML individuales como `ejercicio_01.html`, `ejercicio_02.html`, `ejercicio_03.html`, etc.
- Ejercicios más avanzados sobre arrays, DOM, cuestionarios, tablas de multiplicar y juegos.
- Carpeta `imgs/` con recursos gráficos utilizados por algunos ejercicios.

## Cómo usarlo

1. Clona el repositorio.
2. Abre cualquiera de los archivos `.html` en tu navegador.
3. Si quieres ver la vista general, inicia con `index.html`.

## Tecnologías

- HTML
- JavaScript
- CSS embebido dentro de algunos archivos HTML
